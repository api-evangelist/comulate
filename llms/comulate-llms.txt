# Comulate

> Comulate is an accounting automation and revenue intelligence platform for large insurance brokers. It captures carrier statement data across spreadsheets, PDFs, and email, reconciles direct-bill and carrier-payables transactions against policies, and surfaces commission forecasting, variance tracking, and missing-commission detection. It is delivered as a hosted application at app.comulate.com with native read/write connectors to broker management systems. No public developer API, developer portal, API reference, or machine-readable specification is published as of 2026-08-14; the production API host api.comulate.com is live but returns HTTP 401 on every path.

## Products
- [Direct Bill Automation](https://www.comulate.com/direct-bill-automation): capture carrier statement data (spreadsheets, PDFs, email) and auto-reconcile transactions to policies
- [Carrier Payables Automation](https://www.comulate.com): streamline payables, flag discrepancies, manage disbursement timing
- [Revenue Intelligence](https://www.comulate.com): commission forecasting, variance tracking, missing-commission detection
- [Balance](https://www.comulate.com/balance): broker accounting balance surface

## Integrations
- [Integrations](https://www.comulate.com/integrations): native read/write connectors for Applied Epic, BenefitPoint, AMS360, Microsoft Dynamics, and Salesforce. Comulate reads and writes to the broker's AMS and ERP, which remain the source of truth for policy and accounting data. These are vendor-built connectors, not a published integration API.

## Developer surface
- No developer portal. comulate.com/developers, /docs and /api all return HTTP 404; developer.comulate.com and docs.comulate.com do not resolve in DNS.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, or Postman collection is published at any Comulate host.
- No client libraries or SDKs exist in npm, PyPI or RubyGems, and there is no public GitHub organization.
- No MCP server, A2A agent card, or /.well-known/ discovery document is served on any host.
- https://api.comulate.com is a live first-party API host. Its root returns HTTP 200 with the body "200 OK" (a health check); every other path, including /openapi.json and all /.well-known/* paths, returns HTTP 401 "Unauthorized". The API exists and is customer-gated; its contract is not published.
